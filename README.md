## How I build with AI

- **Spec first, small slices** — written specs, acceptance criteria and architecture decision records, shipped in small, reviewable slices with AI coding agents (mainly Claude Code).
- **Verified, not trusted** — agent-written code passes the same gates as hand-written code: type checks, dependency boundaries, property-based tests, real-browser tests and accessibility checks.
- **AI reads, code decides** — models read and suggest, tested code handles anything touching money or data, and a person approves anything customer-facing.
